# Choose the palette and style

Open Design is optional. When it is installed, show the creator its local HTML gallery on a new `youtube-video-builder` invocation and ask which palette/style they want. Reuse an explicit selection for the same video without repeating the question.

Refresh the gallery into the writable video project, not the installed skill folder:

```sh
python3 <skill-root>/scripts/build_style_gallery.py --output <project-root>/open-design-style-browser.html
```

The builder discovers `/Applications/Open Design.app/Contents/Resources/open-design` or the path supplied with `--root` / `OPEN_DESIGN_ROOT`. It indexes actual HTML examples and linked DESIGN.md files, rather than importing the entire catalog. Show/open the saved HTML with the available browser or local-file tools. `open-design-style-browser.html` is generated by `scripts/build_style_gallery.py`; no prebuilt copy is shipped, because its links point at the Open Design files on the machine that built it. Regenerate it when installations or paths change. If Open Design is unavailable, say so and use the creator's stated palette, their own design references, or the example defaults in SKILL.md §4.

For the selected style, read its DESIGN.md, relevant token CSS, and matching HTML example; inspect the rendered example where browser tools are available. Extract the palette, contrast roles, typography hierarchy, shape/spacing and layout ideas. Adapt them into the HyperFrames composition and its matching shorts templates, including animation colors and caption emphasis, rather than changing only a single CSS hex value. Preserve the approved splash timing/motion, adapting its colors and typography when the creator's selection applies to the whole video, balanced presenter treatments, readable factual graphics, face clearance and final MP4 verification. Record the chosen example path and design decisions in BRIEF.md.

The blue/green channel look is one selectable direction. Selecting a design reference does not require copying that product's name, logo, text or a complete website layout into the video. Do not generate the presenter's likeness or treat an illustrative style example as source evidence for spoken claims.
